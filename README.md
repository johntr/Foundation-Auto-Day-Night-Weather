# Weather Cycle

A [Foundation](https://www.polymorph.games/foundation/) mod that automatically cycles the weather through **day → sunset → night → twilight**, with a chance of rain, instead of you picking it by hand. It can also tilt the sun to change shadow length and direction.

## Install

1. Copy the `Weather Cycle` folder into `Foundation/mods/`.
2. Enable **Weather Cycle** in the game's Mods menu.
3. Enable it for your save (or start a new game with it on), then save once. Foundation stores the active mods in each save.

## Configure

Everything is in `config.lua`:

| Setting | Default | What it does |
|---|---|---|
| `Phases` | Day 8, Sunset 3, Night 6, Twilight 3 | The cycle's order and the length of each phase in **in-game days** (1 day = 60 s at 1× speed). The full cycle is about 20 minutes. |
| `CanRain` (per phase) | on for Day | Lets that phase roll rain instead. |
| `RainChance` | `0.2` | Chance (0–1) of rain for phases that have `CanRain` set. |
| `FollowGameSpeed` | `true` | `true`: the cycle speeds up with fast-forward. `false`: it always runs at 1× pace. It stops when paused either way. |
| `SunPitchOffset` / `SunYawOffset` | `20` / `0` | Tilts the sun in degrees. Pitch raises or lowers it; yaw swings it around the map. |
| `Verbose` | `true` | Logs each weather change. |
| `Debug` | `true` | Shows a popup when the cycle starts and logs the lighting probe. Set to `false` once it's working. |

Available weathers: `WEATHER_SUNNY`, `WEATHER_DUSK`, `WEATHER_NIGHT`, `WEATHER_RAINY`. The game has no separate sunrise setting, so twilight uses the dusk look.

## How it works

- A small component (`scripts/COMP_WEATHER_CYCLE.lua`) counts down each phase and calls `COMP_ENVIRONMENT_SYSTEM:changeCurrentWeather()`.
- Foundation has no documented "map loaded" hook. The mod starts by registering a dummy taxation function (`scripts/level_hook.lua`) that the game initializes on every map load. It appears in the tax menu as **"Weather Cycle (no effect)"** and never taxes anything.
- The component is saved with the map. A guard ensures only one cycle runs, even when a save contains extra copies.
- Sun tilt rotates the `Environment/SunContainer` object.

## Known limitations

- Weather changes are instant. The game's lighting timeline uses a transition time of 0, and the modding API has no documented way to blend it.
- After a load, the cycle always starts at Day. It doesn't remember its place in the cycle.

## Debugging

The logs are in the game's user folder (on Linux/Proton: `steamapps/compatdata/690830/pfx/drive_c/users/steamuser/Documents/Polymorph Games/Foundation/`):

```sh
grep 'Weather Cycle' modding.log
```

The game writes to its log with a delay, so give it a minute after loading before checking.
